# 🪔 Diwali Sales Analysis

This project analyzes Diwali sales data to identify customer purchasing patterns, top-selling products, high-performing regions, and factors affecting sales performance.

## 🎯 Project Objective

- Analyze Diwali sales data using Python.
- Understand customer purchasing behavior.
- Identify top-selling product categories.
- Find high-performing states and occupations.
- Generate insights to improve sales and customer experience.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis

- Gender-wise sales analysis
- Age-group analysis
- State-wise sales performance
- Occupation-wise purchasing behavior
- Product category analysis
- Marital status analysis
- Top-selling products
- Customer purchasing patterns

## 🔍 Key Insights

- Identified customer segments contributing most to sales.
- Analyzed top-performing states and product categories.
- Identified purchasing trends across different customer groups.
- Used data visualization to understand sales patterns.
